# Skills instaladas

Curadas para diseño de páginas web diferenciadas (anti "look genérico de IA"),
branding, copy persuasivo y auto-revisión.

| Skill | Origen | Uso |
|---|---|---|
| `taste-skill` | https://github.com/Leonxlnx/taste-skill | Reglas anti-slop de tipografía/color/componentes |
| `hallmark` | https://github.com/Nutlope/hallmark | 21 temas + 57 checks anti-AI-slop para landing pages |
| `brand-guidelines` | https://github.com/nexu-io/open-design | Referencia para armar identidad de marca propia |
| `copywriting` | https://github.com/nexu-io/open-design | Copy de landing pages y homepages |
| `marketing-psychology` | https://github.com/nexu-io/open-design | Principios de persuasión para copy y precios |
| `design-review` | https://github.com/nexu-io/open-design | Auditoría visual antes de publicar |
| `digits-fintech-swiss-template` | https://github.com/nexu-io/open-design | Referencia de estilo fintech/swiss (b/n + acento) |
| `editorial-burgundy-principles-template` | https://github.com/nexu-io/open-design | Referencia de estilo editorial de autor |

Cada carpeta conserva su propia licencia de origen. No modificar el contenido
de terceros directamente; si algo necesita ajuste, crear una skill propia que
lo referencie.
